## 拼豆游戏 项目总览

### 项目
- 引擎：Cocos Creator 3.8 + TypeScript
- 玩法：参考 LongB_unityads.html（Luna Playground 出的 Color Sort 类拼豆填色小游戏）
- 当前任务：游戏玩法已基本完成，要开发**关卡编辑器**

### 关键文件
- `assets/scripts/data/LevelData.ts` — 关卡数据结构 + 校验（已有，可直接复用）

- `assets/scripts/game/BeanBoard.ts` — 棋盘管理（Flood Fill 找连通组，matched 锁死）

- `assets/scripts/game/BeanTray.ts` — ⚠️ **文件内容错误！当前内容是 GameController 的副本，BeanTray 类本身缺失**——需要先修复

- `assets/scripts/game/FloatingBeanQueue.ts` — 悬浮组管理
- `assets/scripts/game/BeanInput.ts` / `FlyingBean.ts` — 输入和飞行豆动画

### LevelData 结构（编辑器要按这个导）
- `id`, `name`
- `rows`, `cols`
- `colors[]` — `{id, hex}` 颜色板
- `cells[]` — 长度 = rows*cols，元素 `{targetColorId, beanColorId}`（beanColorId=-1 表示空格）
- `trayCapacity`, `trayBeans[]` — 暂存槽容量与初始豆子

### 校验规则（编辑器也要遵循）
- trayCapacity > 0
- 暂存豆子数 ≤ 容量
- 每个 targetColorId / beanColorId 都必须在 colors 里登记
- **数量守恒**：每种颜色，棋盘上 beanColorId == colorId 的数量 + 暂存槽里的数量 == 棋盘 targetColorId == colorId 的底数

## 关卡编辑器（已交付 v1）

- 文件：`拼豆游戏/level-editor.html`（独立 HTML，无需服务器，浏览器直开）
- 四步向导：1.配置（行列 2~20 + 颜色增删改，白色 id=0 不可删）→ 2.涂底色 → 3.涂棋子（含"空"橡皮）→ 4.导出
- 交互：左侧色板点选（键盘 1~9 快捷）、棋盘点击/拖动涂色（pointer 事件 + elementFromPoint，鼠标触屏通用）
- 步骤 2 隐藏棋子只显示底色；步骤 3 底色变 0.38 透明度作背景、棋子为圆点覆盖层
- 导出：LevelData JSON 完全对齐 `assets/scripts/data/LevelData.ts`；支持下载/复制/导入回显
- 校验：编辑器内置 validateLevel 与游戏 validateLevelData 逻辑一致（数量守恒等）
- 兼容性测试：`temp/verify-editor.mjs`（node --experimental-strip-types 直接导入游戏 TS 校验函数），6/6 通过
- 默认值：8×8 全白（底/棋均 id=0），trayCapacity=30
