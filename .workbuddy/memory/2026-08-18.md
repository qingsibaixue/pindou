### LevelData 结构（编辑器要按这个导）
- `id`, `name`
- `rows`, `cols`
- `colors[]` — `{id, hex}` 颜色板
- `cells[]` — 长度 = rows*cols，元素 `{targetColorId, beanColorId}`（beanColorId=-1 表示空格）
- `trayCapacity`, `trayBeans[]` — 暂存槽容量与初始豆子

### 校验规则（编辑器也要遵循）
- trayCapacity > 0
- 暂存豆子数 ≤ 容量
- 每个 targetColorId / beanColorId 都必须在 colors 里登记
- **数量守恒**：每种颜色，棋盘上 beanColorId == colorId 的数量 + 暂存槽里的数量 == 棋盘 targetColorId == colorId 的底数
