# Web Portal Submission Checklist

## Build

- [ ] Production Web Mobile build opens without console errors.
- [ ] Browser language selects English outside Chinese locales.
- [ ] The home-screen language button switches all visible UI.
- [ ] Touch and mouse controls both work.
- [ ] Progress and language survive a page refresh.
- [ ] ZIP contains `index.html` at its root and no absolute asset paths.
- [ ] ZIP is tested after extraction through a local HTTP server.
- [ ] No Cocos splash, third-party SDK, external request, ad or payment code is active.

## Listing assets

- [ ] 630 × 500 itch.io cover.
- [ ] 16:9 promotional cover.
- [ ] 3–6 gameplay screenshots without browser chrome.
- [ ] English title, description, controls and tags copied from `WEB_PORTALS_EN.md`.
- [ ] Privacy statement says progress and language are stored locally only.

## Publishing order

1. Publish itch.io as an HTML game.
2. Submit the same build to CrazyGames Basic Launch.
3. Apply to Poki with the prototype, but review its web-exclusivity terms before agreeing to publication.
