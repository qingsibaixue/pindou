## 当前代码实际行为

- 本地保存：当前关卡 ID、已完成关卡 ID 列表。
- 设备能力：在支持的平台调用轻震动；初始化时展示平台分享菜单。
- 网络：游戏业务代码没有主动请求接口。
- 不采集：姓名、手机号、头像、账号资料、精确位置、通讯录、相机、麦克风、相册、设备标识、支付信息。

## 建议平台声明

本游戏无需注册登录。游戏仅在用户设备本地保存关卡进度，用于继续游戏和展示已解锁关卡；不上传至开发者服务器。游戏可能调用设备轻震动以提供落豆反馈，用户可通过系统设置关闭震动。分享入口由小游戏平台提供，分享行为由用户主动触发。
