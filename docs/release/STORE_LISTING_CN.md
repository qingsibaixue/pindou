# 《拼豆小世界》上架文案

## 基本信息

- 游戏名称：拼豆小世界
- 推荐分类：休闲 / 益智
- 核心标签：拼图、收纳、治愈、像素、单机
- 屏幕方向：竖屏
- 适合人群：喜欢拼图、颜色整理和轻度解谜的玩家

## 文案版本

一句话：整片搬运彩色拼豆，把错位图案重新拼完整。

短介绍：拿起成片豆群，在20格托盘中巧妙中转，完成50幅彩色拼豆图案。

完整介绍：

《拼豆小世界》是一款强调“大量豆豆一起移动”的治愈系拼图游戏。观察每片豆群的颜色与轮廓，把它们整片抬起、暂存并倒回正确底色。随着关卡推进，棋盘会从爱心、花朵和小鱼，扩展到横向列车、纵向火箭、五色场景与六色终章。托盘只有20格，而后期豆群可达36颗，需要把大块自然拆成两轮完成。没有倒计时，可以按照自己的节奏享受成片落豆的反馈。

## 玩法卖点

1. 不是逐颗点击：一次移动12–36颗连通豆群。
2. 50个独立关卡：正方形、横向和纵向棋盘交替出现。
3. 20格托盘策略：大豆群需要20+余量的两轮中转。
4. 舒适反馈：连锁落豆动画、轻震动和完整颜色归位。
5. 单机进度：关卡进度保存在设备本地。

## 审核备注

游戏核心操作为：点击棋盘上的同色连通豆群，再点击托盘或对应颜色的棋盘空位。第10关开始会出现超过20颗的豆群，玩家需完成两轮中转；这是设计机制，不是卡死。游戏不含登录、支付、广告、聊天、用户投稿或排行榜。
